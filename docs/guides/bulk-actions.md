# Bulk Actions Guide

> Use bulk actions to select multiple todos and perform operations on them all at once. Delete, complete, or mark incomplete several items with just a few clicks.

## Quick Start

The bulk actions feature lets you work with multiple todos simultaneously. Instead of deleting or completing items one-by-one, select several items and execute an action on all of them together. Bulk actions are available whenever you have multiple todos in your list.

---

## For Customers

### How to Select Multiple Todos

1. Navigate to your todos page
2. Click the **"Select"** button in the top-right corner of the Tasks card
3. Selection checkboxes will appear next to each todo
4. Click the checkbox next to any todo to select or deselect it
5. The selection count updates in the toolbar (e.g., "2 selected")

### How to Mark Multiple Todos Complete

1. Enter selection mode (see "How to Select Multiple Todos" above)
2. Select the todos you want to mark complete
3. Click the **"Mark Complete"** button in the bulk action bar
4. All selected todos will be marked complete with checkmarks
5. Selection mode automatically exits

### How to Mark Multiple Todos Incomplete

1. Enter selection mode with one or more todos selected
2. Click the **"Mark Incomplete"** button in the bulk action bar
3. All selected todos will lose their checkmarks and become incomplete
4. Selection mode automatically exits

### How to Delete Multiple Todos

1. Enter selection mode with one or more todos selected
2. Click the red **"Delete"** button in the bulk action bar
3. All selected todos will be permanently removed from your list
4. Selection mode automatically exits

### How to Use "Select All"

1. In selection mode, click the **"Select All"** button in the bulk action bar
2. All todos in your list will be selected
3. The button changes to **"Deselect All"** when everything is selected
4. Click it again to deselect everything

### How to Exit Selection Mode

1. Click the **"Cancel"** button in the bulk action bar, or
2. Click the **"Cancel"** toggle button in the header (replaces "Select")
3. Selection mode closes and your selections are cleared
4. No changes are applied if you cancel

### Tips

- **Quick Actions:** Use "Select All" to select all todos, then mark them complete or delete them all at once
- **Partial Selection:** You don't need to select everything—select only the todos you want to modify
- **Individual Completion:** While in selection mode, you can still click the completion checkbox on individual todos to toggle them without affecting your selection
- **Delete Button:** The red Delete button is only enabled when you've selected at least one item, preventing accidental clicks
- **Counting:** The selection count in the toolbar updates instantly as you check or uncheck items

## FAQ

**Q: Can I select all todos and then deselect specific ones?**
A: Yes! Click "Select All" to select everything, then click individual checkboxes to deselect the ones you don't want. The "Select All" button changes to "Deselect All" when all items are selected.

**Q: What happens if I mark incomplete a todo that's already incomplete?**
A: Nothing—the todo remains incomplete. The bulk action applies to all selected items regardless of their current state.

**Q: Can I undo a bulk delete?**
A: No, deletions are permanent. Make sure you've selected the correct todos before clicking the Delete button.

**Q: Do bulk actions work on completed todos?**
A: Yes, you can select and modify both completed and incomplete todos. A bulk operation applies to all selected items regardless of their completion state.

**Q: Can I still delete individual todos while in selection mode?**
A: Yes, the delete button (trash icon) still appears on hover for individual todos even when in selection mode. It will only delete that one item, not affect your selection.

## Troubleshooting

**Issue:** The "Select" button is disabled or not visible
**Solution:** The "Select" button only appears when you have at least one todo in your list. Add a todo first, then try again.

**Issue:** Action buttons are grayed out (disabled)
**Solution:** Make sure you've selected at least one todo. The selection count in the toolbar should show a number greater than 0.

**Issue:** Selection mode exited unexpectedly
**Solution:** Selection mode automatically exits after you perform a bulk action (delete, mark complete, or mark incomplete). To exit without making changes, click the "Cancel" button.

**Issue:** I selected todos but nothing happened when I clicked an action button
**Solution:** Verify that the selection count shows a number greater than 0. If buttons are grayed out, you may not have any todos selected.
